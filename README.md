# BCDock Homebrew tap

The Homebrew formula for [bcdock](https://github.com/bcdock/cli), the command-line interface for [BCDock](https://bcdock.io): managed Microsoft Dynamics 365 Business Central environments on Azure.

## Install

```bash
brew install bcdock/tap/bcdock
```

Upgrade with `brew upgrade bcdock`. Check the install with `bcdock version`.

`bcdock.rb` is updated automatically on every CLI release, so changes to it here would be overwritten.
